# Liquid Glass Launcher

Launcher Android façon iOS 26 : verre liquide, animations fluides, bibliothèque d'apps, recherche, mode modification et guide de bienvenue.

**Télécharger l'APK :** https://github.com/bryanguim/liquid-glass-launcher/releases/latest/download/LiquidGlass.apk

L'APK est compilé automatiquement par GitHub Actions à chaque push sur `main`.
